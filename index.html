AttendX

Smart RFID Attendance Management System

An IoT-based smart attendance management system designed to connect RFID-based identification with ESP32, REST APIs, PostgreSQL and a modern web dashboard.

  • RFID-based student identification using ESP32 and an RFID reader
  • Hardware-to-server communication through Wi-Fi and REST APIs
  • Student, faculty and attendance-session management
  • PostgreSQL-backed attendance records
  • Duplicate-attendance prevention
  • Role-based application architecture
  • Attendance monitoring and analytics dashboard
  • Hardware setup and firmware documentation

02

ParkSense

IoT Smart Parking & Real-Time Monitoring System

An IoT-powered smart parking system designed to use ESP32 and distance/proximity sensors to detect parking occupancy and provide live parking information through a web dashboard.

  • ESP32-based parking-space monitoring
  • Sensor-based occupancy detection
  • Available, occupied and unknown slot states
  • Configurable sensor thresholds and calibration
  • Sensor-reading filtering and state stabilisation
  • Wi-Fi device-to-server communication
  • Device heartbeat and health monitoring
  • Historical parking occupancy and utilisation analytics
